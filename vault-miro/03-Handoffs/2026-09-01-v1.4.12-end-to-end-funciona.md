## TL;DR

**APK v1.4.12 instalada + setup ejecutado → wireless debug = 1,
service BOUND, flow OLAX QS-tile completo, sin dialog "Selecciona
launcher", sin pantalla oscura.** Esto es **el primer build que
funciona end-to-end desde la APK sin trucos de la PC**.

## Lo que se cambió

### MiroLauncherActivity.kt (v1.4.12)
- `hasWriteSecureSettings()` chequea el permission al inicio
- Si falta, log error con el comando adb exacto + handoff a ESLauncher
  (el user NO se queda en pantalla negra — antes crasheaba)
- v1.4.11 fallaba post-reinstall por esto mismo

### adb_tablet v1.2.3
- `cmd_setup` verifica el grant después de `pm grant`
- Si falla, reintenta 3 veces con backoff 1s
- Si los 3 fallan, retorna error claro con instrucción de debug

## Bug menor detectado

`getRecentTasks()` solo retorna las tasks en el **recents tray**
(es decir, las que tienen UI visible reciente), NO todas las apps
corriendo en background. `dumpsys activity recents` confirma que
solo aparecen `RecentsOverviewActivity` y `ESLauncher` en la lista.

Para listar **apps corriendo reales** necesitaríamos:
- `ActivityManager.runningAppProcesses` (deprecated pero funcional)
- o `UsageStatsManager.queryEvents` con `PACKAGE_USAGE_STATS` (permiso special)

Esto es **un fix aparte** para v1.4.23. Por ahora, la UI funciona
estructuralmente (botones, contador, navegación) y el "Cerrar
todas" cierra lo que `getRecentTasks()` retorne (que en este
momento son solo el launcher y la activity de recents — básicamente
no-ope para el caso real).

## Lo que SÍ funciona

- El botón "Abrir recientes" de la notification → abre la
  RecentsOverviewActivity (fullscreen, tema dark, layout bien
  renderizado)
- El botón "X" cierra la activity
- El "CERRAR TODAS" llama `killPackageStatic` por cada task (que
  ahora mismo solo afecta MiroLauncherActivity y ESLauncher, no
  apps de usuario)

# 2026-09-01 — v1.4.21 — Notification action buttons fire via Activity (Android 12 trampoline fix)

## TL;DR

Los botones "Abrir recientes" y "Cerrar recientes" de la notification
persistente **ya no hacen nada visible** en Android 12+ por el
**Notification Trampoline Restrictions** (target SDK 31+).
v1.4.21 lo arregla cambiando el PendingIntent de `getBroadcast` a
`getActivity` apuntando a una nueva `RecentsActionActivity`.

## Causa raíz

Cadena original (v1.4.20):
```
notification action tap
  → PendingIntent.getBroadcast(ACTION_KILL_ALL_RECENT)
  → RecentsActionReceiver.onReceive
  → onKillAllCallback()
  → MiroAccessibilityService.startKillAllRecents()
  → RecentTasksCleaner.start()
  → openRecentsScreen()
  → service.startActivity(intent)    ← BLOQUEADO por Android 12
```

En Android 12 (API 31), un `BroadcastReceiver` que se dispara desde
un notification action **NO PUEDE iniciar activities ni services**.
El sistema silenciosamente descarta la transición. No hay
SecurityException, no hay log — solo el botón no hace nada.

## Verificación del fix

Pre-fix (v1.4.20 en la tablet):
- Tap a "Cerrar recientes" → no se ejecuta el callback, no se abre
  Recents, no hay log de error.
- El receiver se registraba en el manifest con
  `android:exported="false"` y el intent-filter correspondiente, pero
  eso no importa: la restriction es sobre el tipo de transición
  (broadcast → startActivity), no sobre la export del receiver.

Post-fix (v1.4.21):
```
$ adb shell am start -n com.miro.a11y/.RecentsActionActivity -a com.miro.a11y.KILL_ALL_RECENT
miro    : recents action: received action=com.miro.a11y.KILL_ALL_RECENT
miro    : recents action: kill-all fired
miro    : recents: state=OPENING_RECENTS — opening Recents screen
miro    : recents: GLOBAL_ACTION_RECENTS returned true
miro    : RECENTS_OPENED
miro    : recents: DONE

$ adb shell am start -n com.miro.a11y/.RecentsActionActivity -a com.miro.a11y.OPEN_RECENTS
miro    : recents action: received action=com.miro.a11y.OPEN_RECENTS
miro    : recents action: open-recents fired
miro    : startOpenRecents: dispatched GLOBAL_ACTION_RECENTS
```

## Cambios

1. **Nueva** `app/src/main/java/com/miro/a11y/RecentsActionActivity.kt`:
   - Activity exported=true con `Theme.Translucent.NoTitleBar`
   - `noHistory=true` + `excludeFromRecents=true` para no ensuciar
     la task list
   - Valida `intent.package == getPackageName()` antes de invocar
     cualquier callback (defensa contra otras apps)
   - Invoca el callback static (mismo path que el receiver viejo)
   - `finish()` inmediato

2. **`RecentTasksNotifier.kt`**:
   - `buildActionPendingIntent()` ahora usa `getActivity` apuntando a
     `RecentsActionActivity` (en vez de `getBroadcast` apuntando a
     `RecentsActionReceiver`)

3. **`AndroidManifest.xml`**:
   - Removido el `<receiver .RecentsActionReceiver android:exported="false">`
   - Agregado el `<activity .RecentsActionActivity android:exported="true">`
     con intent-filter para las 2 actions

4. **`app/build.gradle.kts`**:
   - versionCode 34 → 35
   - versionName 1.4.20 → 1.4.21
